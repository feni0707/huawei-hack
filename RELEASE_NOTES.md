# v1.0.0

Первый публичный релиз: финальное онлайн-решение задачи «Gas pipeline construction» и всё, что нужно, чтобы его
воспроизвести и сравнить с другими.

## Что внутри

- `solutions/final_online.cpp` — финальная посылка (scorefit + предохранитель зон + страховка через тень best fit).
  Открытые тесты: **30.1539 / 32.1**, 0 WA/TL, ≈ 0.2 с CPU на самом тяжёлом тесте.
- `solutions/cangjie/` — порты на Cangjie 1.0, ответы побитово совпадают с C++.
- `scripts/` — прогон на интеракторе, параллельный бенчмарк, генераторы тестов (классы по мотивам открытых и
  100 «общих»), верхние оценки KPI, оффлайн-стенд на 1700 тестов за секунды.
- `EXPERIMENTS.md`, `docs/`, `solutions/archive/` — журнал экспериментов (в том числе отклонённых), разбор тестов,
  идеи, описание стратегии.

## Известные ограничения

- Закрытые тесты 16–30 недоступны, поэтому результат на них — оценка по сгенерированным наборам, а не измерение.
- Страховка через тень best fit проверена только на оффлайн-наборах; на открытых тестах не меняет ни одного ответа.
- `solutions/hybrid.cpp` (вшитые открытые тесты) не годится для посылки: ≈ 11 с CPU на тесте 15 при лимите 5 с.
- Материалы организаторов в `materials/` и условие в `docs/` не покрыты лицензией MIT, см. `NOTICE.md`.
