# Журнал экспериментов

После **каждого** эксперимента (новая идея, параметр, исправление) допишите строку в таблицу — в том числе неудачные:
отрицательный результат тоже экономит время команде. Новые записи — внизу.

Как получить цифры:

```bash
python3 scripts/gen_tests.py --clean          # gen-наборы (seed 1 по умолчанию — у всех одинаковые)
python3 scripts/bench.py solutions/<имя>.cpp  # open Σw + avg KPI по классам, WA/TL, CPU
python3 scripts/bench.py --diff build/bin/<старое> build/bin/<новое>   # что именно поменялось по тестам
```

Колонки:
- **open** — Σ w·KPI на `materials/tests` (макс 32.1).
- **gen** — средний KPI по классам `build/gen/*` (seed указывать, если не 1): `alt` alternating, `per` periodic,
  `pha` phases, `rnd` random_bursts, `srt` sorted_groups.
- **CPU** — макс. CPU решения на тест, с, замер `-j 1` (при параллельном прогоне CPU завышен).
- **WA/TL** — должны быть 0; иначе посылать нельзя.
