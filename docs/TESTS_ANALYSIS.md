- **UB KPI** — тривиальная верхняя оценка: траншея не укорачивается, значит её финальная длина
  ≥ `20·ceil(пик суммарной длины живых труб / 20)`; `UB = живых в конце / это`. Оценка не учитывает фрагментацию

## Характер тестов (что видно глазами)

- **1** — пример из условия (вес 0.1).
- **2, 3, 4, 6** — маленькие ручные кейсы на 1–3 сегмента; проверяют аккуратную упаковку и повторное использование дыр.
- **5** — укладки отсортированы по длине: 125 труб длины 1, затем 125 длины 2, …, 125 длины 40;
  после каждой группы удаляется каждая вторая труба этой группы (40 блоков удалений по ~63). Провоцирует фрагментацию:
  дыры размера `L` остаются, а дальше приходят только более длинные трубы.
- **9** — то же на степенях двойки: по 1000 труб длины 1, 2, 4, 8, 16, 32, после каждой группы удаляется каждая вторая (по 500).
  UB всего 0.663 — большая часть потерь неизбежна.
- **10** — длины 1..5, сначала ~5400 укладок периодическим паттерном `3 5 2 5 1 3 1` (сумма периода = 20!),
  затем массовые удаления (выборочно, с шагом 2–3 PID), затем чередование `4 1 -K`.
- **7** — паттерн «растущая длина + труба длины 1» с редкими удалениями.
- **8, 13** — один генератор (общий префикс 388 команд): почти строгое чередование «уложить / удалить недавнюю»,
  доминируют длины 5, 10, 16 (и 15, 6). Живых в конце мало (3–5 тыс. м) при Σ уложенного 34–44 тыс. — повторное
  использование освободившегося места критично.
- **12** — похожий класс (длины 5/10/14/20…, одиночные удаления), но живых в конце 70 %.
- **11, 15** — один генератор (общий префикс 4999 команд): случайные длины 1..40 (короткие 1–7 частые), удаления
  пачками до 9–14, удаляются как свежие, так и очень старые трубы. 15 — самый тяжёлый тест (200 000 команд, вес 10).
- **14** — фазы: ~15 000 укладок почти только длины 1 (без удалений), затем смешанные фазы с удалениями,
  в конце ~2300 укладок длинных труб (среднее 7–18, до 40). Ловушка для стратегий, которые «размазывают» короткие трубы.

## Вывод для стратегии (наблюдения)

- KPI считается **только по финальному состоянию**: важны финальная длина траншеи и то, что лежит в конце.
  Копать лениво — каждый лишний сегмент навсегда в знаменателе.
- Удалённые трубы освобождают место, которое можно переиспользовать, — для 8/13/15 это основной резерв.
- Тесты с весом 4 и 10 (12–15 и закрытые 16–30) дают 106 из 116.1 баллов — приоритет оптимизации именно на них.
- Тай-брейк — суммарное CPU-время: при равном score быстрее = лучше (C++ с быстрым вводом-выводом).
