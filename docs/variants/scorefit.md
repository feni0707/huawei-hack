# Вариант «scorefit»: best fit + потоки по признакам, чьи носители умирают вместе

- **Владелец:** feni (+ Claude). **Ветка:** `feni/scorefit` (от `dev`). **Файл:** `solutions/scorefit.cpp`.
- **Статус:** рабочее решение, **open 29.058 / 32.1** (best fit 28.376, naive 4.91), WA/TL = 0, CPU на 15 ≈ 0.43 с (`-j 1`),
  память в худшем случае 71 МБ. Подробный журнал — `EXPERIMENTS.md` (строки `feni (Claude)`).

## Что важно знать команде (находки, полезные любому варианту)

1. **Тест 15 (и 11) двухфазный**: первая половина — только короткие 1..7 (удаляются свежие), вторая — только
   длинные 8..40 (удаляются в основном свежие длинные, ~18 % удалений — старые короткие из «окна» в глубине).
   Класс `random_bursts` этого **не** воспроизводит (best fit 0.998 против 0.947 на 15). Добавлен класс
   **`two_phase`** в `scripts/gen_tests.py` — best fit на нём 0.93–0.945, как на 15. Закрытые 27–30 (вес 10),
   вероятно, такие же — мерьте на нём.
2. **Потолок 15 ≈ 0.963, а не 1.0.** ~16 тыс. м потерь — дыры от старых коротких, удалённых во 2-й фазе
   (длинные туда уже не лезут). Оставшиеся ~7 тыс. — «вечные» остатки 1–7 м между выжившими длинными;
   оракул (знает будущее) доводит 15 до 0.971, но кто из длинных выживет — случайно, онлайн не выучить.
3. **Память:** решение с массивами по позициям траншеи и ростом ×2 на тесте «200 тыс. труб по 40 м без
   удалений» (T = 8·10⁶) занимало 286 МБ > 256 МБ. Проверяйте: `python3 scripts/gen_tests.py --class stress --count 3`.
4. Best fit очень силён: штрафы «мёртвых» остатков, модель ожидаемых потерь дыры, first/last/worst fit,
   оценка риска соседей — всё в пределах шума или хуже (см. журнал).

## Алгоритм

База — **best fit**: свободные промежутки в корзинах по точной длине (< 128) + `set` для больших; граничные метки
для склейки за O(1); хвост траншеи используется последним; докопка минимальная. Плюс:

1. **Сторона внутри дыры:** остаток прижимается к более молодому соседу (больший PID) — он скорее умрёт, и остаток
   сольётся. +0.02 obj.
2. **Потоки (главная идея).** Онлайн ищем признак, носители одного значения которого *умирают вместе*: для
   соседних удалений в одной пачке считаем долю совпадений признака и сравниваем с ожидаемой при независимости
   (каппа). Признаки: чётность индекса в серии равных длин, чётность PID. Если каппа ≥ 0.6, трубы делятся на
   два потока: A кладётся к левому краю «граничного промежутка», B растёт влево от правой границы роста F
   (участками по 400 м). Какая бы половина ни умерла — освобождается одна большая сплошная дыра.
   Тот, кто по статистике умирает чаще, идёт в B. Если прогноз *подтвердился* на помеченных трубах
   (смертность B − A > 0.5), B идёт сразу к границе роста, минуя дыры.
   Эффект: тест 5 0.50 → 0.94, 9 0.50 → 0.64 (UB 0.663), gen sorted_groups 0.50 → 0.79 (UB 0.83).
3. **Не «замуровывать» дыру у умирающего соседа:** штраф точному попаданию, если сосед из класса длины с
   высокой *текущей* интенсивностью смертей (доля недавних удалений / доля живых), за вычетом интенсивности
   класса самой новой трубы. Тест 10: 0.66 → 0.78.

## Как мерить (быстрый стенд)

```bash
c++ -std=c++17 -O2 -DSIM -o build/sim_sf solutions/scorefit.cpp     # оффлайн-симулятор, без интерактора
build/sim_sf materials/tests/*.in                                     # KPI по тестам; SF="i=v ..." — параметры
for s in 1 2 3 4 5 6; do python3 scripts/gen_tests.py --seed $s --out build/gen$s --clean; \
  python3 scripts/gen_tests.py --class two_phase --count 6 --seed $s --out build/gen$s --clean; done
```

Целевая метрика при подборе: `obj = 10·two + 4·(alt + pha) + 2·(srt + per + rnd)` по ~200 gen-тестам (seed 1–6),
открытые тесты — контроль. Текущее: obj 22.217, по классам alt 0.956, per 0.758, pha 0.998, rnd 0.998,
srt 0.792, two 0.930. Разрыв до UB: alt 3.4 %, per 3 %, srt 4 %, two 6.6 % (из них ~3.6 % неустранимо).

## Идеи, которые не сработали (чтобы не повторять)

| Идея | Результат |
|---|---|
| Штраф «мёртвого» остатка (< мин. недавней длины) | 15: 0.947 → 0.943 — дробит большие дыры |
| Exact fit, иначе worst fit | тест 2 → 1.0, 15 → 0.950, но alt −1.5 % |
| First / last / worst fit | хуже best fit везде |
| Модель ожидаемых потерь дыры W(r) | two −1.4 % |
| Риск смерти соседа по возрасту (Фенвик по живым) | +0.001 |
| «Мёртвый остаток ≥ k → в хвост» | шум ±0.01 obj |
| Адаптивный размер участка потока B | нейтрально |
| Сродство «тот же поток той же серии» | без эффекта |
